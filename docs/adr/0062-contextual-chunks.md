# ADR-0062 — عنوان سند و بخش همراه هر قطعه در جست‌وجو

وضعیت: **پیاده‌شده و سنجیده‌شده** (سنجش بدون کلید، با مجموعهٔ `qa/retrieval-eval`). [ADR-0061](0061-semantic-knowledge-embeddings.md) و KNO-007 را کامل می‌کند.

## ۱. مسئله

سند بلند به قطعه‌های حدود ۸۰۰ نویسه‌ای بریده می‌شود. قطعه‌ای که می‌گوید «کرایهٔ برگشت بر عهدهٔ خریدار است، مگر جنس معیوب باشد» کلمهٔ «مرجوعی» را ندارد؛ آن کلمه فقط در عنوان سند («راهنمای مرجوعی کالا») و تیتر بخش («هزینه‌ها») است. پس پرسش «هزینهٔ مرجوعی بر عهدهٔ کیست» نمی‌توانست این قطعه را از قطعهٔ هم‌شکل سند «راهنمای ارسال» تشخیص دهد.

## ۲. تصمیم

1. **عنوان سند و تیتر بخش** (هدینگ‌های مارک‌داون `#` تا `######`) به‌صورت `context` کنار هر قطعه ذخیره می‌شود (ستون `knowledge_chunks.context`، مهاجرت `0098`).
2. **context فقط به چیزی که جست‌وجو می‌شود می‌پیوندد:** متن جست‌وجوی واژگانی (`search_text`)، embedding محلی، و ورودی embedding معنایی (ADR-0061). **متن خود قطعه (`text`) دست‌نخورده می‌ماند**، چون نقل‌قول‌ها با آن راستی‌آزمایی می‌شوند و به مدل داده می‌شود. خود هدینگ هم از `text` بیرون می‌ماند.
3. سند بدون هدینگ یک بخش است و context‌اش فقط عنوان سند.
4. فقط **نسخه‌هایی که از این پس تأیید می‌شوند** context می‌گیرند. قطعه‌ها append-only‌اند؛ سند موجود با نسخهٔ تازه دوباره قطعه می‌شود. قطعهٔ قدیمی `context` تهی دارد و مثل قبل رفتار می‌کند.

## ۳. سنجش (قفل «اگر بهتر نشد نگه نمی‌داریم»)

مجموعهٔ ارزیابی با چهار سند بلند و ۱۲ پرسش `section-context` گسترش یافت، با همان کد قبل اجرا شد، سپس با کد جدید (hit@5 و MRR، ۷۸ پرسش):

| دسته             | hit قبل ← بعد | MRR قبل ← بعد                  |
| ---------------- | ------------- | ------------------------------ |
| کل               | ۰٫۷۸ ← ۰٫۸۶   | ۰٫۶۵ ← ۰٫۷۵                    |
| section-context  | ۰٫۷۵ ← ۱٫۰۰   | ۰٫۶۱ ← ۰٫۷۹                    |
| natural-question | ۰٫۸۳ ← ۱٫۰۰   | ۰٫۵۴ ← ۰٫۷۲                    |
| cross-lingual    | ۰٫۱۷ ← ۰٫۳۳   | ۰٫۱۷ ← ۰٫۳۳                    |
| paraphrase       | ۰٫۵۰ ← ۰٫۶۰   | ۰٫۴۶ ← ۰٫۴۶                    |
| synonym          | ۰٫۸۰ ← ۰٫۸۰   | ۰٫۵۱ ← ۰٫۶۴                    |
| morphology، typo | ۱٫۰۰ ← ۱٫۰۰   | ۰٫۷۱ ← ۱٫۰۰ / ۰٫۷۱ ← ۰٫۸۸      |
| confusable       | ۱٫۰۰ ← ۱٫۰۰   | **۱٫۰۰ ← ۰٫۸۸** (افت؛ یک پرسش) |

دسته‌ای که هدف بود بهتر شد و بیشتر دسته‌ها هم؛ تنها افت، MRR دستهٔ `confusable` (چهار پرسش) است. پرسش‌های بدون‌پاسخ بدون تغییر ماندند (۳ از ۴ هنوز نتیجه برمی‌گردانند؛ یک مسئلهٔ جدا است).

## ۴. محدودیت‌ها

- مجموعه کوچک و ساختگی است؛ سندهای بلند فقط چهار تا. اثر روی سندهای واقعی (بدون هدینگ مارک‌داون، مثلاً متن استخراج‌شده از PDF) کمتر خواهد بود: آنجا فقط عنوان سند می‌پیوندد.
- هدینگ فقط به شکل مارک‌داون شناخته می‌شود. تیتر «۱. مهلت‌ها» یا خط تنها در متن PDF هدینگ حساب نمی‌شود.
- `context` در نتیجهٔ بازیابی به مدل داده نمی‌شود؛ فقط در رتبه‌بندی شرکت می‌کند.

## ۵. بازگشت

نسخهٔ بعدی بدون `chunkSections` می‌تواند به `chunkText` برگردد؛ ستون اضافه بی‌اثر می‌ماند. مهاجرت فقط افزودنی است.
