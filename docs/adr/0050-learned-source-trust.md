# ADR-0050 — اعتماد منبعِ یادگیرنده

وضعیت: **پیشنهادی و پیاده‌شده** (فاز ۳، بخش اول). [ADR-0040](0040-research-source-trust.md) و [ADR-0049](0049-research-progress-and-gaps.md) را کامل می‌کند.

## زمینه

ادمین باید فهرست «منابع رسمی» (`research.official_domains`) را دستی نگه دارد، و هر بار که منبع مشابهی در اختلاف‌ها پیش می‌آید دوباره تصمیم بگیرد. اما تصمیم‌های خودش در اختلاف‌ها (`trust`) همین اطلاعات را دارد.

## تصمیم

۱. **یادگیری فقط از تصمیم خودِ ادمین.** از آخرین تصمیمِ هر اختلافِ «معتبر دانسته شد» که یک صفحهٔ وب را برگزیده، نشانی همان صفحه (از خروجی همان زمان) خوانده می‌شود. دانش تأییدشده و «بی‌اهمیت» شمرده‌نمی‌شود.
۲. **پیشنهاد، نه تغییر خودکار.** دامنه‌ای که دست‌کم ۲ بار معتبر دانسته شده و هنوز رسمی نیست در تنظیمات تحقیق (حوزهٔ workspace) با دکمهٔ «افزودن به منابع رسمی» پیشنهاد می‌شود؛ چیزی خودبه‌خود عوض نمی‌شود.
۳. **هرگز گسترده‌تر از اعتماد ادمین.** پیشنهاد دقیقاً همان میزبانِ (host) صفحه‌های معتبرشده است (بدون `www.`)، نه دامنهٔ بالاتر؛ پس افزودن بیش از آنچه ادمین پذیرفته اعتماد نمی‌کند. دامنه‌های رسمی داخلی و دامنه‌های فهرست‌شده پیشنهاد نمی‌شوند.
۴. **توصیه‌گر اختلاف از آن استفاده می‌کند.** صفحهٔ عمومی از دامنهٔ یادگرفته‌شده، بین صفحهٔ عمومی عادی و صفحهٔ رسمی قرار می‌گیرد؛ دلیل «شما پیش‌تر بارها صفحه‌ای از همین دامنه را معتبر دانسته‌اید» نشان داده می‌شود. صفحهٔ رسمی هیچ‌وقت «یادگرفته‌شده» علامت نمی‌خورد و رتبه‌اش بالاتر می‌ماند.
۵. **API:** `GET /settings/research-source-suggestions` (`workspace.read`).

## باگ‌ها و ریسک‌های پیش‌بینی‌شده

| ریسک                                                    | رفع                                                                             |
| ------------------------------------------------------- | ------------------------------------------------------------------------------- |
| تصمیم قدیمیِ عوض‌شده هنوز شمرده شود                     | فقط آخرین تصمیمِ هر اختلاف (`distinct on`)؛ روی PostgreSQL اجرا و بررسی شد      |
| مرجعی که دیگر در خروجی نیست خطا بدهد                    | آن ردیف نادیده گرفته می‌شود (تست)                                               |
| افزودن میزبان به دامنهٔ بالاتر گسترش یابد               | پیشنهاد دقیقاً همان میزبان است؛ تطبیق با زیردامنه‌ها طبق قاعدهٔ فعلی فهرست رسمی |
| دامنهٔ مشابه (`notexample.com`) مطابق شود               | تطبیق با مرز نقطه (تست)                                                         |
| دامنهٔ رسمی «یادگرفته‌شده» شود و رتبه‌اش افت/افزایش کند | صفحهٔ رسمی علامت `learned` نمی‌گیرد (تست)                                       |
| نوشتن همزمان فهرست رسمی دو ویرایش را نابود کند          | ذخیره با `expectedSequence`                                                     |

## پیامدها

مهاجرت ندارد. بدون تصمیم‌های تکراری هیچ پیشنهادی نمی‌آید و رفتار فعلی بدون تغییر می‌ماند.
